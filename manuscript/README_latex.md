# Building the manuscript

`main.tex` is the hand-maintained, compilable Elsevier CAS (`cas-sc`) source and the **single source
of truth** for title, authors, abstract, keywords, body, tables and declarations. It pulls in the
bibliography (`references.bib`), the generated result tables (`tables/*.tex`) and the figures
(`../docs/img/*.pdf`, via `\graphicspath{{../}}`). The two other manuscripts are mechanical ports
regenerated from it by scripts, so they cannot drift in content.

## Targets
- **`main_springer.tex` — Springer `svjour3`, two-column — submission target: *International Journal
  of Information Security* (Springer Nature).** Generated by `src/analysis/port_springer.py` from
  `main.tex`: Springer title page (authors, affiliation, corresponding e-mail, ORCIDs), abstract +
  `\keywords`, body with two-column table variants (`tables_springer/`, re-emitted from `tables_ieee/`
  with the journal's "Online Resource 1" wording for supplement pointers), spanning figures, a
  *Statements and Declarations* section (funding, competing interests, ethics, data/code availability,
  author contributions from the CRediT roles, generative-AI use) and numbered references via
  `spmpsci` with DOIs rendered as full `https://doi.org/` links. `supplement_springer.tex` is the same
  supplement with the front page IJIS requires for supplementary files (Online Resource 1).
  Class/style files `svjour3.cls`, `svglov3.clo` (Springer's macro package linked from the IJIS
  submission guidelines) and `spmpsci.bst` are included in this folder.
- **`main.tex` — Elsevier CAS single-column (`cas-sc`)** — canonical source; `\title[mode=title]`,
  `\author...[orcid=]`, `\credit` + `\printcredits`, `highlights` + `graphicalabstract` environments,
  numbered refs via `natbib[numbers]`. Class files `cas-sc.cls`, `cas-dc.cls`, `cas-common.sty`,
  `cas-model2-names.bst` are included.
- **`main_ieee.tex` (IEEEtran)** — two-column backup port (`figure*`/`table*`, `tables_ieee/`),
  regenerated by `src/analysis/port_ieee.py`.

## Regenerate and compile
```bash
# from the repository root
python -m src.analysis.make_paper2_latex_tables    # result tables -> tables/ and tables_ieee/
python -m src.analysis.port_ieee                   # main_ieee.tex from main.tex
python -m src.analysis.port_springer               # main_springer.tex, tables_springer/, supplement_springer.tex
python -m src.analysis.build_pdfs                  # main, supplement, main_ieee (release pipeline)

cd manuscript
pdflatex main_springer && bibtex main_springer && pdflatex main_springer && pdflatex main_springer
pdflatex supplement_springer && bibtex supplement_springer && pdflatex supplement_springer && pdflatex supplement_springer
# (supplement_springer resolves main-paper cross-references from main_springer.aux; compile main first)
# CAS: latexmk -pdf main.tex   |   IEEE: latexmk -pdf main_ieee.tex
```
Needs a TeX distribution (TeX Live / MiKTeX) with `pdflatex` + `bibtex` on PATH; `microtype`,
`hyphenat`, `mathptmx`, `cite`, `hyperref` are standard packages.

## Notes
- **Author metadata** (affiliation, co-authors, ORCIDs, CRediT roles, funding/conflict statements) lives
  once, in the `main.tex` front matter; the ports read it from there.
- The **gated-update pseudocode** is a captioned `figure` in `main.tex` (`\label{fig:algorithm}`, a
  `verbatim` block inside); the two-column ports turn it into `figure*` like every other figure, and
  they also span the supporting-evidence map (`tab:evidence_map`) as `table*` because it overflows one
  column.
- **Wide tables** use `\footnotesize` inside `table*`; if a row overflows, wrap the `tabular` in
  `\resizebox{\linewidth}{!}{...}`.
- **Highlights / graphical abstract** (`highlights.md`, `../docs/img/graphical_abstract.pdf`) are
  Elsevier-specific submission items and are not used by the Springer target.
